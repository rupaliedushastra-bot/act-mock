STEP 2: API Key Banao
================================================================
1. Login karne ke baad:
   Top-right mein apna naam click karo → "SMTP & API"
   
   YA seedha jao:
   https://app.brevo.com/settings/keys/api

2. "Create a new API key" click karo
3. Name dena hoga — kuch bhi likho, jaise:
   "EduQuest SAT Portal"
4. "Generate" click karo
5. API Key copy karo (ek hi baar dikhega!)
   (Kuch aisa dikhega: xkeysib-XXXXXXXXXXXXXXXX...)
   
   ⚠️ IMPORTANT: Is key ko abhi copy karke safe jagah 
   rakho — baad mein dobara nahi dikhega!

STEP 3: Sender Email Verify Karo
================================================================
Brevo chahta hai ki email sirf verified address se jaaye.

1. Jao: https://app.brevo.com/senders/domain/list
2. "Add a sender" click karo
3. Email: rupali.eduquest@gmail.com dalo

5. Gmail inbox check karo — Brevo ka verification email aaya hoga
6. Verification link click karo
7. Sender verified ✅

================================================================
COMMON ERRORS:
================================================================
❌ "unauthorized" ya 401 error
   → API key galat hai, dobara copy karo

❌ "sender not found" ya 400 error  
   → Step 3 mein sender email verify karo

❌ Email spam mein ja raha hai
   → Gmail mein mark as "Not Spam"
   → Brevo dashboard mein "Domain Authentication" karo
      (Settings → Senders & IP → Authenticate a domain)
